# framework

Reusable, metadata-driven CMS compliance data framework (Program Audit
ODAG/CDAG, Part C ODR, Part C SLIDA, etc.) on AWS.

## Contents

- [`docs/design/schema-design.md`](docs/design/schema-design.md) — table
  design, naming conventions, and the mock-data scenarios below.
- [`mock-data/cms_compliance_framework_tables.xlsx`](mock-data/cms_compliance_framework_tables.xlsx) —
  reference/metadata tables plus the two core tables
  (`ComplianceRequestControl` / "CRC" and `ComplianceBatchOverride` /
  "CRC Override"), each populated with every mock scenario's rows
  combined directly into that one tab — no separate per-scenario tabs.
